ConsoleLAN 1.3.2 para Windows x64

Incluye tema claro/oscuro y selector Español/English, con preferencias persistentes y aplicación inmediata sin salir de la sala. Actualizar desde 1.0 conserva sus consolas y reservas.

Necesita una VPN ya configurada con UDP entre los PC, Ethernet por cable y Npcap instalado por separado desde https://npcap.com/#download.

Este instalador NO incluye Npcap. Su licencia gratuita limita el uso y prohíbe la redistribución externa. Revise las condiciones aplicables en la web oficial.

La tarea de firewall es opcional y está desmarcada. Si la selecciona, indique la IPv4 VPN LOCAL de este PC. Solo se autorizan este ejecutable, la interfaz que tiene esa IP y UDP 32189-32190. No se cambia ninguna ruta, NAT, puente ni configuración IP doméstica.

Microsoft Visual C++ Runtime x64 se instala si no está presente. Internet y DNS son opcionales: activa acceso local e Internet y configura la .1 de la sala como gateway/DNS en la consola. No se garantiza PSN, UPnP ni un tipo de NAT. El funcionamiento de una partida requiere validar el hardware y el modo LAN del juego siguiendo docs/ACEPTACION.md.

Los datos del usuario se conservan al desinstalar. La aplicación no tiene firma de editor; Windows puede mostrar una advertencia de reputación.

Nuevo en 1.2: acceso local opcional por adaptador propio Wintun firmado, incluido con su licencia. Solo requiere elevación al activarlo; la aplicación principal puede funcionar como usuario normal. Solo permite acceder a las consolas locales, sin modificar la Ethernet o VPN domésticas.

1.3.0: cualquier puerto TCP de las consolas locales, FTP pasivo y protección temporal WFP contra bucles del adaptador propio. La aplicación y el auxiliar deben actualizarse juntos. No se cambian las opciones de reenvío o las reglas persistentes del firewall de otras interfaces.

1.3.1: optimización del acceso local PC/consolas con eventos Wintun/Npcap, colas sin pausa fija bajo carga y exclusión de capturas propias. No cambia la VPN, las IP ni las reglas de firewall existentes. La velocidad física debe validarse en cada equipo.

1.3.2: lotes nativos de Npcap limitados al acceso de este PC a sus consolas locales. Turnos de hasta 64 paquetes; sin cambios al transporte de salas/VPN. Actualice la aplicación y ConsoleLAN.Access.exe juntos.
